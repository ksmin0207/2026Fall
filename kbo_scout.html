지표 사전 & 데이터 안내

비율 통계는 필터에 해당하는 원시 기록을 먼저 합산한 뒤 계산합니다. 아래 기준값은 기능 시연용으로 지정한 값입니다.

AVG / OBP / SLG / OPS
타율 H÷AB / 출루율 (H+BB+HBP)÷(AB+BB+HBP+SF) / 장타율 TB÷AB / 출루율+장타율.
ISO / BABIP
순장타율 SLG−AVG / 인플레이 타율 (H−HR)÷(AB−SO−HR+SF). BABIP만으로 운이나 실력을 단정할 수 없습니다.
BB% / K%
볼넷 또는 삼진 ÷ 타석(PA). 투수는 상대 타자 수(BF)를 분모로 사용합니다.
ERA / WHIP
평균자책점 = ER×27÷아웃 수. 이닝당 출루허용 = (H+BB)×3÷아웃 수.
K/9 / BB/9 / HR/9 / K−BB%
9이닝당 삼진·볼넷·홈런 = 각 카운트×27÷아웃 수. K−BB%는 탈삼진율−볼넷율입니다.

타자: AVG .270, OBP .345, SLG .410, OPS .755, ISO .140, BB% 9%, K% 19%. 투수: ERA 4.50, WHIP 1.45, K% 20%, BB% 9%.
